# Комната памяти — демонстрационная сцена

Виртуальная комната в браузере: 2D-сцена со слоями и параллаксом, предметы с историями.
Сделана как демо для проекта «Вкорни» (vkorni.com).

## Что внутри

- Сцена на SVG: стена, окно, комод, кресло, столик с лампой — каждый слой двигается
  со своей скоростью, поэтому появляется глубина без 3D.
- Камера следует за курсором на компьютере и за наклоном телефона.
- Шесть предметов: лампа (включает свет), шкатулка с письмом, патефон с записью голоса,
  фотографии, видео с плёнки, плед с историей.
- Звук и видео не запускаются сами: только по нажатию.
- Вес страницы — около 600 КБ, включая запись голоса и видео. Без библиотек и сборки.

## Две версии

- `/` — плоская комната: слои, параллакс, свет лампы, шесть предметов.
- `/iso/` — изометрическая комната: разрез комнаты без передних стен, та же логика
  предметов. Сцена собирается скриптом `tools/gen_iso.py` (изометрия с раскладкой
  координат комнаты), поэтому мебель можно переставлять в коде, а не в редакторе.

Переключение между версиями — кнопкой в углу.

## Запуск

Открыть `index.html` в браузере. Всё статично, размещается на любом хостинге.

## Что нужно заменить на реальные материалы

- `assets/voice/1974.mp3` — запись голоса (сейчас демонстрационная, синтез речи);
- `assets/video/archive.mp4` — фрагмент домашнего видео;
- `assets/photos/*.svg` — фотографии комнаты или семьи;
- подписи и текст письма — в `app.js`, объект `CONTENT`.
